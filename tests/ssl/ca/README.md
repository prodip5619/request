# Generating SSL Certs for tests

Certs are generated for TLS tests. The localhost, client and server certs for use in test are generated by running;
```
./gen-all-certs.sh
```

The CA configuration and the server, client, and localhost certificate
scripts set a validity period of 3,650 days (10 years). In `gen-client.sh`,
the `-days 1095` option on the CSR-generation command does not set the issued
certificate's validity; the signing command uses `-days 3650`. The separate
self-signed certificate generated by `../gen-test.sh` is also configured for
3,650 days. Certificates can be updated at any time. The shell scripts must
be checked out with LF line endings so they run correctly in bash/sh on Linux
and macOS.

The self-signed cert used by `tests/server.js` is generated separately by
running `../gen-test.sh`. The RSA key used to check OAuth signatures in
`tests/test-oauth.js` is kept as `../oauth-rsa.key` and must not be regenerated,
because the expected signatures in that test depend on it.
