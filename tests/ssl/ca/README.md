# Generating SSL Certs for tests

Certs are generated for TLS tests. From `tests/ssl/ca`, generate the CA,
localhost, client, and server certificates by running:
```
./gen-all-certs.sh
```

The CA configuration and the server, client, and localhost certificate
scripts set a validity period of 3,650 days (10 years). In `gen-client.sh`,
the `-days 1095` option on the CSR-generation command does not set the issued
certificate's validity; the signing command uses `-days 3650`. The separate
self-signed certificate generated by `tests/ssl/gen-test.sh` is also
configured for 3,650 days. Certificates can be updated at any time. The shell
scripts must be checked out with LF line endings so they run correctly in
bash/sh on Linux and macOS.

The self-signed certificate used by `tests/server.js` is generated separately.
From the repository root, run this in a POSIX-compatible shell:

```sh
cd tests/ssl && sh gen-test.sh
```

`gen-test.sh` writes `test.key` and `test.crt` relative to the current working
directory, so run it from `tests/ssl` to place them where the test server
expects them. The RSA key used to check OAuth signatures in
`tests/test-oauth.js` is kept as `../oauth-rsa.key` and must not be regenerated,
because the expected signatures in that test depend on it.
